# 🚙 Expedice Pilátů z Kalibiku

Tento projekt slouží pro vytvoření offline expediční aplikace a interaktivního roadbooku.

## Cíle projektu

- Klikací PDF s navigací do Mapy.com
- Offline PWA aplikace pro Android
- Databáze checkpointů a průjezdných bodů
- Generování GPX a dalších formátů

```
database/
app/
pdf/
icons/
docs/
```
